# Notes for coding agents

Before touching UI controls, follow the ui-sdk skill if it's installed (`npx skills@latest add vercel-labs/ui --skill ui-sdk`) and read `node_modules/@ui-sdk/react/docs/llms.txt`. To build a new component, search `node_modules/@ui-sdk/react/docs/core.md` by heading and read `rendering.md` next to it.

Run `npm test` and `npm run build` before pushing.
